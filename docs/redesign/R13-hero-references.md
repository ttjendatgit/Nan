# R13: Hero reference notes (internal)

Purpose: extract design THINKING for an object-led cultural Hero, not to copy any site.

**Sources.** Web research found few documented cases. Most results were template listings. The one useful case study is Clay's write-up of Art Bridges (an Awwwards-recognised cultural foundation site). Everything else below comes from established print, exhibition and editorial practice (museum wall labels, exhibition catalogues, campaign posters, Swiss/editorial grids, East Asian vertical scrolls). Those principles are marked *(practice)*.

## 1. Unusual composition
- **"Artwork first"**: the object is the star and every other element exists to set its context. Art Bridges drew on print and physical gallery spaces rather than web patterns.
- *(practice)* Strong compositions come from ONE structural device the whole frame obeys: a horizon or plinth line, an axis, a margin rail, a vertical scroll. Elements that each follow their own logic read as a collage.
- *(practice)* Placing an object relative to the frame's EDGES (resting on a line, touching a margin) feels designed. Floating it in the middle reads as a product shot.

## 2. Typography hierarchy
- Serif and sans pairing, readable and sophisticated, complementing the artwork rather than competing with it (Art Bridges).
- *(practice)* Use one typographic idea, not several. Scale contrast between display and caption type of 10:1 or more reads as editorial. Similar sizes read as web UI.
- *(practice)* Vertical setting has deep roots in Vietnamese and East Asian scrolls (câu đối), so it is a cultural reference here, not a trend effect.

## 3. Object placement
- *(practice)* Exhibitions give an object a ground (plinth, wall line, floor) and a label at a fixed relationship to it. The relationship, not the position, is what makes the placement feel intentional.
- *(practice)* An object's own geometry (here: the pivot, the axis, the guards, the arc) can define where everything else aligns.

## 4. Negative space
- "A clean, tranquil space" that gives each piece room to command attention (Art Bridges).
- *(practice)* An empty area is justified only if it is the counter-mass to something specific: the room above an object on a plinth, the field a large word pushes against. Space left over after placing content is not justified.

## 5. Editorial micro-information
- *(practice)* Catalogue conventions: object number (N° 01), materials line, a single caption. Two or three at most, set in small caps or small italic. Each one is a label for something on screen; none is scattered decoration.

## 6. CTA treatment
- Gallery pages stay immersive while program pages give "clear, actionable steps" (Art Bridges). In a Hero that means one clear primary action, quiet otherwise.
- *(practice)* Use one primary button and one text link sitting on the same rail or line as the caption system. Avoid a pair of pills under a paragraph.

## 7. What makes it intentional rather than random
- *(practice)* Every element can be explained by the one device: "it sits on the horizon", "it starts where the axis ends". If an element's position can only be explained as "there was space", it is random.
- Restraint: subtle motion only, with the static frame doing the work (Art Bridges).

Sources: [Clay, "Behind-the-Scenes of Art Bridges' Success"](https://clay.global/blog/artbridges-behind-the-scenes); [Awwwards Moco Museum element](https://www.awwwards.com/inspiration/exhibitions-moco-museum) (exhibition overview, seen for reference only).

## R14 addendum: principles for an object-generated frame

The same sources apply (searches again surfaced mostly templates); these are *(practice)* principles from poster, exhibition and architectural graphics:
- **Derive, don't place.** Pick the object's strongest geometric property (axis, pivot, tips, mass) and let it set every other coordinate. Test: remove the object, and the remaining type should still trace its outline or axis.
- **One decision per frame.** Swiss axial typography, a poster's justified foot line, a roof sheltering a sign: each is ONE rule. Two rules read as a collage.
- **Scale contrast replaces proximity.** In fashion and object campaigns a huge object with small type, far apart, creates tension through distance; the type does not need to sit next to the object to belong to it.
- **Edges are structure.** Type that touches the frame's edge (flush, justified, or at a fixed margin) reads as poster typesetting; type floating in the middle reads as a web heading.
- **Shelter.** In Vietnamese architecture the roof (mái) defines the space under it; an object can likewise define the space where words are allowed to live.

## R15 addendum: the Hero as a scene

- **Whole-space typography.** Exhibition research treats floors, walls and ceilings as the presentation surface: visitors "do not view the objects in the two-dimensional mode in a standstill posture", and type that leaves the panel gains scale and expression ([Yonsei study, IJDesign](https://ijdesign.org/index.php/IJDesign/article/download/2144/731)). For the Hero: type can live on a plane of the scene (floor, wall), not in a text box.
- **Ambiance type.** Museum practice distinguishes "large scale typographic or visual treatments whose main objective is to create an ambiance or conceptual setting" from title and interpretive panels ([AAM Exhibitionist](https://aam-us.org/wp-content/uploads/2024/04/13EXHSP14Neumann_NutsandBolts_BetterByDesign.pdf)).
- **Viewing position sets scale.** In environmental graphics the viewer's eye level determines letter size and placement ([Made Good Designs](https://madegooddesigns.com/environmental-graphic-design/)): in a scene, near things are big and far things small, which is a hierarchy that needs no columns.
- **Full-bleed object hero.** In 3D-hero practice the render IS the frame, and type is placed against the frame's edges or bleeds across them ([Awwwards elements, e.g. Naya Studio](https://www.awwwards.com/inspiration/hero-screen-3d-animation-naya-studio)). Cropping the TYPE (never the object) lets letterforms become architecture.
- *(practice)* Cinema: a letterboxed frame turns a composition into a still from a film; credits and titles live in the frame's margins, not on the image.

## R17 addendum: object cinema

- Recent winners "commit to one strong visual concept rather than mixing effects", with "restrained effect application (1-2 strong moments not 10)" and respect for reduced motion ([svilenkovic, Awwwards 2026 3D](https://svilenkovic.com/3d/awwwards-2026-3d)); performance on real mid-range devices is judged ([hontran.dev](https://www.hontran.dev/blog/best-award-winning-websites-2026)).
- *(practice, product cinema)* A product shot stops reading as "an image on a page" when the object is turned in three dimensions toward the camera: one near edge, one far edge. The frame then has depth by itself, before any type exists. Type placed at the far side of a turned object reads as distant; type at the near edge reads as close. Scale and position stand in for a grid.
